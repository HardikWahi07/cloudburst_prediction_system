# Cloudburst Prediction System

## Project Overview

An AI-powered weather monitoring and cloudburst risk prediction system
designed for the Entire Indian Himalayan Region.

## Objectives

- Collect meteorological data.
- Analyze historical weather patterns.
- Predict extreme rainfall and cloudburst-associated risks.
- Generate location-based risk maps.
- Provide early warning alerts.
- Visualize weather conditions through an interactive dashboard.

## Technology Stack

- Frontend: React.js
- Backend: Node.js and Express.js
- Machine Learning: Python and Scikit-learn
- Database: PostgreSQL
- Maps: Leaflet and OpenStreetMap
- Weather Data: Open-Meteo and available IMD datasets

## Geographical Scope

Entire Indian Himalayan Region (IHR).
